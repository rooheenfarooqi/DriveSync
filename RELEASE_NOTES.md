## DriveSync 0.9.0 beta 1

The first public beta of DriveSync, a real-time desktop search engine for Windows.

- Finds files by name as you type, across the folders you choose or every drive
- Filters by type, folder and date, plus `ext:`, `in:` and `type:` operators
- Summarizes Word, PDF, PowerPoint, Excel, text and code files on this PC; nothing is uploaded
- Keeps the index current with live file watching and a scheduled refresh
- Runs in the system tray, with a global shortcut to open search from anywhere
- Updates itself from this page

**Installing:** download `RooheenFarooqi.DriveSync-win-Setup.exe` below and run it. No administrator rights are needed.
This beta isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC": choose
**More info → Run anyway**.
